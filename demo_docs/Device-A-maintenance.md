# Device-A 设备维护SOP

## 维护周期

- 日常点检：每日开机前检查链条和急停按钮
- 小保养：每300工作小时，加注链条润滑油
- 大保养：每1500工作小时，检查电机轴承和链条磨损

## 故障排查流程

1. 记录设备当前状态和故障现象。
2. 确认现场安全，切断设备外部供电。
3. 检查线缆、螺栓、链条和保护装置。
4. 完成维修后执行空载测试。
5. 空载运行30分钟，确认正常后恢复使用。

## 安全要求

1. 维护前必须上锁挂牌。
2. 设备下方禁止站人。
3. 维修电机前必须等待设备充分冷却。

## 工单要求

发生维修后创建维护工单，记录：

- 设备型号
- 故障现象
- 支持证据
- 处理方案
- 工单状态

工单状态使用：

```text
created / processing / resolved
