# Device-B 设备维护SOP


## 设备维护流程与故障排查SOP
> 当监控发现设备参数异常时，按照下面顺序排查
1. 记录当前设备运行参数：电机温度、负载、运行时长
2. 确认现场安全，切断设备外部供电
3. 外观检查：线缆破损、螺栓松动、链条变形
4. 通电空载测试，观察电机运行声音与温升
5. 定位故障部件，完成维修后空载试运行30分钟，确认无异常，再恢复生产使用

## 安全注意事项
1. 维护作业必须上锁挂牌，防止误启动
2. 设备举升下方禁止站人
3. 维修电机前必须等待充分冷却，避免烫伤

## 维护记录填写规范
发生故障维修后，需要创建维护工单，记录：设备型号、故障现象、证据描述、处理方案。
工单状态：created / processing / resolved
